# GridFall: Neon City Architect

A JavaFX city-building game where players build and manage a city's power grid. Place buildings, generate electricity, meet power demands, and keep the grid stable while dealing with random events.

## Features

- 15×15 building grid
- Different power sources and consumer buildings
- Electricity generation and consumption system
- Grid stability and overload management
- Random events such as heatwaves, solar flares, and cyber attacks
- Building repair and deconstruction
- Undo and save functionality

## Tech Stack

- **Language:** Java 21
- **UI Framework:** JavaFX 21
- **Build Tool:** Maven
- **Library:** Gson
- **IDE:** IntelliJ IDEA

## Getting Started

### Prerequisites

- Java 21 or higher
- Maven
- IntelliJ IDEA (recommended)

### Installation

1. Clone the repository.
2. Open the project in IntelliJ IDEA.
3. Allow Maven to load the dependencies.
4. Run `Main.java` to launch the game.

Alternatively, run from the terminal:

```bash
mvn clean javafx:run
```
